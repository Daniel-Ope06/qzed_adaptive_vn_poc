\unnumberedchapter{Abstract}
\pagenumbering{roman}

\quad Educational video games promise immersive learning, but most rely on static, linear storylines that fail to adapt to individual student progress. \textit{Dynamic Difficulty Adjustment} (DDA) through Reinforcement Learning (RL) offers a data-driven solution for personalised learning, but integrating these models requires player data telemetry without breaking game immersion. To solve this, this project engineered a bespoke educational visual novel framework using the Godot engine, designed for future deployment on the \textit{QZed} platform. Within this framework, \texttt{JSON} serialisation separated narrative content from engine logic, enabling AI-driven content updates. The system assesses learning in two ways. First, through stealth assessments embedded in dialogue choices that do not feel like tests, alongside quizzes at the end of each chapter. The project successfully created a working adaptive visual novel framework that connects game design with machine learning systems.

\section{Background and Context}

\quad Many educational games use fixed storylines that do not consider how different students learn. \textit{Serious Games} (SGs) need to keep players engaged by adjusting the challenges based on their skills~\cite{11}. Using a set difficulty level ignores learners' changing needs. Adapting the flow of information to individual learning needs can greatly improve understanding. However, creating personalised paths in games is difficult and time-consuming. Reinforcement learning (RL) is a useful method for adjusting difficulty in real time based on user needs. It treats \textit{Dynamic Difficulty Adjustment} (DDA) as a decision-making process, choosing difficulty levels that fit each user without relying on fixed rules. The main challenge is to measure how well a user is learning in real time without disrupting their game experience. This requires ongoing data telemetry and evaluation without disrupting the game flow.


\section{Research Questions}

\quad The original ambition of this project was to deploy a complete game, recruit up to 200 volunteer players, and analyse the AI algorithm's decision logs to map its learning curve. However, engineering a custom visual novel framework from the ground up introduced immense, unforeseen complexities. The sheer volume of labour required to draw custom 2D art assets, code the underlying engine architecture, and write branching story content alongside conceptual quizzes necessitated a strategic refinement in the research focus.

Consequently, rather than evaluating live human metrics, this research pivots to address the foundational architectural questions required to make such an evaluation possible:

\begin{enumerate}
    \item How can a custom visual novel framework be designed to track ongoing stealth assessment data for future use in machine learning?

    \item How can narrative story branching be mathematically formulated as an episodic task to allow an AI model to optimise pathway routing by learning from multiple users?
\end{enumerate}

\section{Scope and Objectives} \label{objectives sec}

\quad Because live human responses cannot be measured accurately without a robust, highly stable data pipeline, this project focuses strictly on the systems engineering required to support future AI integration. Empirical live testing is deferred to a future deployment on the \textit{QZed} platform~\footnote{QZed is an interactive educational learning platform that hosts game-based learning tools, past questions, and resources for students.}.

The immediate objectives are to:

\begin{enumerate}
    \item Engineer a custom visual novel framework capable of capturing learner telemetry.

    \item Formulate the pipeline required for an AI agent to modify the game's pathways based on aggregate student data.
\end{enumerate}


\section{Main Contribution}

\quad This dissertation delivers a functional, telemetry-ready visual novel framework. It gives developers a scalable framework for creating dynamic storytelling, ultimately enabling students to experience an educational environment that adapts to them rather than forcing them to adapt to the software.

\chapter{State-of-the-Art}

\quad Gamification and game-based learning have proven highly relevant in the applied educational discourses of game studies. Sukhov explores applied discourses (i.e., gamification and game-based learning), methodological approaches in game studies, the latest theoretical concepts and discourses, and their applications in education~\cite{1}. Although gamification and game-based learning are similar in nature, they are two different concepts.  The study describes gamification as the application of game mechanics and systems to serious non-game discourses. An early version of this was the “PBL” (Points, Badges, and Leaderboards) model used to create extrinsic motivation for learners and users. Examples of this can be seen in “Duolingo”, “Nike Run Club”, and “Foldit”, with “Foldit” being an exceptional success as the game solved a problem that had been unsolved for 15 years in 3 weeks. Despite its usefulness, the “PBL” model has been criticised for failing to consider intrinsic motivation and for being manipulative. In response to this criticism, SAPS (Status, Access, Power, Stuff), RAMP (Relatedness, Autonomy, Mastery, Purpose) and Octalysis (intrinsic) were developed. Conversely, game-based learning is the design and use of games in the education process. This goes beyond gamifying the learning process and creates games whose purpose is to facilitate learning. Although game-based learning can be applied in various ways, the study focused on simulation video games (SVG) as a case study. For example, vehicle SVGs such as “Microsoft Flight Simulator” (“MSFS”), social SVGs such as “The Sims”, construction and management SVGs such as “Industry Giant”, business SVGs such as “Virtonomics”, government SVGs such as “Democracy”, and medical SVGs such as “Surgeon Simulator” all provide educational opportunities to a wide variety of individuals and learners. Although the study discussed various methodological approaches in game studies, including narratological, ludological, media, and non-reductionist approaches, none of these views stands superior over the others, as they are all essential for improving our understanding of games and their application to education.

\quad Game-based learning has been applied in multiple fields. One study applied game-based learning to enhance cybersecurity awareness using an adaptive visual novel~\cite{2}. This study aimed to assess the users’ gaps in understanding of cybersecurity concepts and practices, assess games developed to enhance cybersecurity awareness using Caserman’s framework, and identify requirements for an adaptable framework. To confirm users’ understanding of cybersecurity concepts, the study conducted a survey where users were asked to identify legitimate and suspicious cases from a list of scenarios. The survey revealed that even among users who claimed to be familiar with cybersecurity concepts, over half falsely classified 6 of 12 scenarios.  Additionally, the study used Caserman’s criteria for evaluating serious games, which consist of serious criteria and enjoyment criteria. The findings revealed that most existing serious games prioritised serious criteria over enjoyment criteria, as shown in the sizeable gap between their modes. To address this imbalance, the study proposed a theoretical framework encompassing five modules: a domain model module, a game engine module, a user interface module, a learning style module, and a user model module. The adaptive capabilities of the proposed framework are supported by the game engine module using Dynamic Difficulty Adaptation (DDA). Although the proposed Educational Visual Novel Adaptive Game (EVNAG) successfully adapts to the user, our study aims to take this a step further by integrating reinforcement learning to personalise and improve the user's learning experience. 

\quad Aside from cybersecurity, gamification and game-based learning have also been applied to engineering. Existing research proposes a method that integrates game-based and flipped learning to educate students about photovoltaic panels~\cite{3}. The study aimed to design and evaluate a hybrid framework that addressed low student participation and poor knowledge transfer. The methodology included a series of steps to integrate flipped and game-based learning. First, students were given an exercise to generate questions based on scientific insights in a video. Second, after sorting the questions by theme into various boxes and assigning points to them based on difficulty, the students were then made to participate in a quiz game. The study surveyed postgraduate students to evaluate the model’s effectiveness, revealing the benefits for retention, content review, classroom focus, student interaction, and motivation. Although this study integrates flipped and game-based learning, it does not utilise machine or reinforcement learning to make the game adaptive. Additionally, there is no evidence of other techniques being utilised to make the game adaptive for learners, in part because the game is played in groups and does not require as much personalisation.

\quad Beyond photovoltaic panels, game-based learning has also proved useful for innovating pedagogy in engineering ethics~\cite{4}. Current education on Engineering ethics is passive and disengaging; this study addresses this issue by proposing a Digital Role-Playing Game (DRPG) based intervention called Engineering Ethics Enigma (3E). The study is based on a theoretical foundation of Cognitive Constructivist Learning Theory, the Game-Based Learning Framework, and the MUSIC (eMpowerment, Usefulness, Success, Interest, Caring) model, which address application, engagement, and motivation, respectively.  The study followed a five-phase development process consisting of instructional planning, pre-production, production, testing, and post-production as shown in Figure~\ref{fig:engineering-ethics}. Following the development of the framework, both expert and student feedback revealed strengths, including content relevance and realism. Additionally, technical reliability and knowledge retention were identified as potential areas for development. Overall, the study found the DRPGBL model’s usability to be considerable despite room for development. Despite the comprehensiveness of this study, a gap is the lack of AI integration of any form to create an adaptive framework.

\quad Beyond the use of game-based learning in various fields, adaptive frameworks for child education have been implemented. Current literature proposes a system that integrates Virtual Reality (VR) and Game-Based Learning (GBL) for children's road safety education~\cite{5}. The study aims to address the challenges in traditional child road safety education, including low engagement and real-world practice. Although video- and presentation-based training sessions are informative, they do not provide a safe way to evaluate children’s learning and competencies before they are needed in the real world. The study used the Unity game engine, VR technology, and Kinect (motion sensing technology) to create a virtual environment for safe practice. The study targeted children in primary- and middle-level education, testing their knowledge before training (A1), after traditional training (A2), after VR-based training (A3), and after children’s gaming and self-practising (A4). The study found children at A4 performed the highest, closely followed by children at A3. This shows that the combination of VR and game-based learning vastly outperforms traditional training methods. Feedback from the children showcased their excitement and engagement with the proposed system, and feedback from teachers and parents appreciated the realism and effectiveness. This study showcases that the education opportunities provided by game-based learning can be easily integrated with existing technology to achieve better results. The study, however, fails to integrate AI, machine learning, or reinforcement learning.

\quad Another way in which gamification and game-based learning have improved in education can be seen in children with dyslexia. Studies have shown that previous methods for instruction design for children with dyslexia lacked personalisation and motivation~\cite{6}. The study aimed to resolve the issue by developing a web application called “Bright Letters: Gamification Strategy for Dyslexic Children”. The study used Gemini 2.5 Flash as the primary algorithm powering the web application. This enabled the seamless implementation of a pipeline encompassing data acquisition, diagnostic evaluation, adaptive recommendation and performance monitoring. The study used statistical analysis to evaluate the system’s performance and discovered that user accuracy and engagement improved. The study also confirmed that the adaptive model offered improved outcomes compared to non-adaptive approaches. This study demonstrated the benefits of adaptive game-based learning for children with dyslexia and the feasibility of developing these systems. Although the study integrates AI to create the adaptive model, it uses an LLM in place of reinforcement learning models, which may prove more suitable for the task. \quad Studies show game-based learning has been used to develop serious games for digital logic education. The study aimed to improve the accessibility and effectiveness of digital logic by integrating an intelligent tutoring system (ITS) within a serious game (SG), resulting in the development of a domain-specific SG called “Gridlock”~\cite{7}. The study integrates the ITS and the serious game using a personalised and need-ware gaming (PING) system. The PING system (Figure~\ref{fig:ping-system}) is a reinforcement learning engine that provides personalised real-time assistance to students playing Gridlock, recommending various paths through the game based on their performance. The study surveyed students who played Gridlock, and the results revealed that they perceived the PING system as a useful scaffolding tool. The PING system’s ability to adapt to individual needs improves students’ performance. Although this system successfully integrates reinforcement learning, the game format includes minigames and quizzes to ensure that students internalise concepts rather than rote memorisation.

\quad Existing literature has shown how game-based learning can be applied in a variety of fields, including cybersecurity, healthcare, engineering, and child education. One study explores various game-based pedagogies (GBPs) to facilitate game-based learning (GBL)~\cite{8}. The two pedagogies discussed include serious game-based learning (SG) and learning by making games (MG). Although both SG and MG aimed to support science learning outcomes, their methodologies differed. While SG uses pre-designed games to support learning, MG involves students creating their own games to deepen understanding. Findings demonstrated that MG students outperformed SG students by an average of 3.5 points. The study went a step further by analysing the effect of gaming hours on learning outcomes. The findings showed that as gaming hours increased, the difference between MG students' and SG students' learning outcomes decreased. Additionally, students with minimal gaming exposure (0-5 hours per week) found the MG approach to be considerably more effective than the SG approach. Conversely, both GBPs benefited students with medium gaming exposure (6-20 hours per week). Although this study provided insight into the utility of various GBPs, it lacked any form of personalisation or adaptive ability for learners. This would have taken this study a step further since gaming exposure played a role in the effectiveness of these pedagogies for students. 

\quad One argument often explored in game-based learning (GBL) literature is the relationship between learning and enjoyment in serious games. The literature assessed the effects of an open learning model (OLM) compared with an open enjoyment model (OEM) in a digital learning game~\cite{9}. Open learner models promote metacognition by displaying the learner model to the student, while open enjoyment models do the same for the enjoyment model. The study designed two versions of the digital learning game, one encouraging OLM and the other encouraging OEM, to teach decimal numbers to 5th and 6th graders. The study used a sample of 159 students (82 males, 77 females) aged 10 to 12 years old, and randomly assigned them to three conditions. The Learning-oriented Condition (LC; N=55) recommended mini-games based on mastery levels. The Enjoyment-oriented Condition (EC; N=54) recommended games based on enjoyment scores. Finally, the Control Condition (CC; N=50) displayed no learning or enjoyment information. The study found that students using the open learner model (OLM) exhibited better in-game and test performance, while the open enjoyment model had no impact on learning outcomes. Although other studies have discussed adapting to the student’s performance, this study explores the potential benefits of giving students autonomy over that adaptation. This study did not employ adaptive visual novels or reinforcement learning.

\quad Game-based learning has been shown to improve learning outcomes, but these effects may vary across individuals~\cite{10}. The study aimed to investigate the effect of adaptive scaffolding within GBL environments. The study used a medical emergency simulator game to explore the impact of adaptive scaffolding. The study matched 62 participants from Dutch universities in pairs based on emergency care experience. Each participant was then randomly assigned to either an adaptive or a non-adaptive scaffolding condition. Although no significant difference was identified between the two conditions, the non-adaptive scaffolding met participants’ needs in 64.9\% of scenarios. Further analysis revealed that tailored scaffolding improved speed, reduced self-regulation, and lowered cognitive load compared with non-tailored scaffolding. These findings imply that adaptive scaffolding may improve learning outcomes within Game-Based Learning (GBL) environments. Although this study implemented adaptive scaffolding, it used an algorithm and could benefit from exploring reinforcement learning instead. 

\quad Another concept explored in the field of gamification and game-based learning is Dynamic Difficulty Adjustment (DDA). Gomes et al. developed a system for Dynamic Difficulty Adjustment in serious games on Psoriatic Arthritis (PsA)~\cite{11}. The proposed system aims to improve therapeutic engagement by continually adapting to the patients’ condition. The system uses AI-driven agents to simulate PsA symptom progression, going beyond existing DDA frameworks that rely on real-time player input. The study collected self-report data from 32 participants (aged 18-30) and then used Reinforcement Learning (RL) and Multi-Armed Bandits (MAB) to perform offline DDA training. The RL algorithms implemented in the simulations included Proximal Policy Optimisation (PPO), Advantage Actor-Critic (A2C), Deep Q-Network (DQN), and Soft Actor-Critic (SAC). Additionally, the study implemented the UCB and e-greedy MAB variants. In this study, MAB algorithms consistently outperformed their RL counterparts, achieving better cumulative rewards and faster adaptation. The personalised mechanism developed in this study can be applied to a wide range of therapeutic games. Although this study applies RL and other advanced algorithms to adapt to users, it is limited to therapeutic games.

\quad Another study aimed to address the issues faced by individuals with rare genetic diseases and neurodevelopmental disorders using serious games~\cite{12}. As conventional methods often lack flexibility, integrating technology such as reinforcement learning can provide adaptable interventions. In line with Piaget’s theory of cognitive development, these serious games have proven to provide benefits, such as emotional recognition and social skills. The ability of reinforcement learning to adjust interventions based on the user’s performance is critical in creating adaptive solutions. The study claims that such personalised and adaptive interventions will cater to the needs of supported individuals regardless of their developmental stage. Although this study highlights the impact of integrating Reinforcement Learning to achieve adaptive serious games, its scope is limited to the medical field. Exploration of the impact of gamification and game-based learning on education as a whole is essential.

\quad Existing research proposes serious games that benefit not only patients but also caregivers. The study developed the iTrain game to improve caregivers' knowledge and skills in caring for stroke survivors~\cite{13}. The study used the Sims game as inspiration for the gameplay. Within the simulation environment developed with Unreal Engine 4, players attempted to meet the needs of a stroke victim that may occur in real-world scenarios. The game scored players based on how well they preserved the virtual stroke survivor’s quality of life for as long as possible. The study tested the game using 14 general medical care workers, 11 non-professional caregivers, and 21 stroke survivors. The findings revealed that the iTrain game positively influenced the attitudes and anxieties of caregivers and stroke survivors in pre- and post-game surveys. The iTrain game used deep reinforcement learning (DRL) because it was well-suited for monitoring learners’ progress and adjusting training curves. The model was suitable because it could transfer knowledge from a model-based teacher to a model-free learner. The study developed a Massive Open Online Course (MOOC) alongside the game for evaluation purposes. Findings showed no major statistical difference between the scores of both the iTrain MOOC and the iTrain game, with both improving the learner’s caring capabilities. 

\quad Some studies may make personalisation and team effort seem distant from each other, but one study attempts to disprove this. The study found that applications of DDA to enhance individual learning have been thoroughly explored in existing research, while a gap remains in DDA for collaborative settings. The proposed DDA algorithm is enabled by the layered architecture of the GRADES framework, which encompasses the Data Collection Layer, the Stealth Assessment Integration Layer, the Adaptive Decision-Making Layer, and the Feedback and Visualisation Layer. Although the study successfully combines reinforcement learning and stealth assessment to achieve Dynamic Difficulty Adjustment in collaborative game-based learning using the GRADES framework, it does not account for serious games with narrative immersion. \quad Studies have attempted to develop a general-purpose framework to personalise student education, regardless of the type of virtual education system (e.g., serious games, intelligent tutoring systems, etc)~\cite{15}. This framework addresses the limitations of traditional education, which employs a one-size-fits-all approach, by augmenting human intelligence with Artificial Intelligence (AI). Additionally, most existing systems are not generalisable, making it complicated to add new topics. This study’s proposed system architecture includes “Educational Concept Ontology”, “Data Collection, Transformation, and Storage”, “Reinforcement Learning”, and “Personalised Assistance Generation”.  The study illustrates with an example how this general-purpose framework can be implemented through a system that provides students with educational material and evaluates their knowledge through quizzes. \quad Research aims to address the unguided nature of existing serious games (SGs) by using a learning-embedded attribute Petri net (LAPN) model and a complementary algorithm to optimise student learning~\cite{16}. LAPNs are a special class of PNs designed to represent a learner’s knowledge, reasoning, and learning process. The learning mechanisms explored in this study include random forest and reinforcement learning (RL). The study performed a comparative analysis of the digital logic serious game “Gridlock” with and without learning optimisation. The findings showed that students with personalised guidance in Gridlock outperform those without any support, with faster completion times. Although this study successfully optimises student learning, it fails to account for narrative immersion.
The existing literature we explored in this section demonstrates the utility of game-based learning and reinforcement learning in developing adaptive systems. Although these studies have contributed to personalisation, none of them encompasses narrative immersion, adaptive visual novels, and reinforcement learning within a single body of work. This paper aims to close this gap by creating an adaptive visual novel that personalises content to the learner using reinforcement and game-based learning.



\chapter{Architecting the Adaptive Engine}

To successfully create an adaptive visual novel, the system needs to connect game development with real-time data tracking. This chapter explains the technical setup and plan for the adaptive visual novel framework.


\section{Foundational Framework Development}

\quad Many digital learning platforms use static text, which can quickly cause learners to lose interest. To address this, the game is designed as a \textit{Narrative-Based Learning Environment} (NBLE). Visual novels are like finite-state machines wrapped in a graphical interface, making them usable as an NBLE. By placing the learner in a story that responds to their actions, the system uses situated cognition to help them remember what they learn better~\cite{CJ}. However, for this environment to work as an intelligent tutor, it needs both narrative presentation and data telemetry.

\quad While visual novel frameworks like \texttt{Ren’Py} offer strong storytelling tools, they limit control over the low-level systems. \texttt{Ren’Py} works best for straightforward stories with fixed choices or paths, making it hard to collect detailed data in real time. Godot Engine was selected to build a custom visual novel framework because its node-based, object-oriented architecture makes it easy to expand the system. The custom framework uses a Global Singleton called the \texttt{GameManager} Autoload. This tool tracks every player action, such as choosing dialogue or clicking on the user interface. This creates a steady flow of information about how players learn.

\quad A critical requirement was ensuring the AI model could update the game's educational content without recompiling the software. To do this, the story content is separated from the engine logic by using \texttt{JSON} (JavaScript Object Notation) to organise the data (Listing~\ref{lst:json}). Instead of hardcoding dialogue into scripts, the game uses lightweight, language-agnostic \texttt{JSON} files to define the characters, text, and pathway logic. This setup lets the game's backend easily send new or AI-customised chapters to the client~\cite{SJ}.

\section{Learner Interface Design}

\quad Educational visual novels can overwhelm learners when they need to understand difficult concepts outside the main story. In traditional e-learning systems, glossaries are in separate tabs. However, \textit{Cognitive Load Theory} suggests that splitting students' attention between different sources of information makes learning harder. To address this issue, the system uses a \textbf{Word Bank}, as shown in Figure~\ref{fig:word-bank}. It highlights important terms directly in the dialogue. When a term is clicked, a pop-up explains the concept without interrupting the story's flow. Additionally, a \textbf{History Transcript} tracks the dialogue flow, as shown in Figure~\ref{fig:dialogue-history}. \section{Stochastic Pathway Routing}

\quad To change the visual novel from a static story to an adaptive tutor, the system uses \textit{Dynamic Difficulty Adjustment} (DDA) based on a reinforcement learning (RL) model~\cite{7}. Instead of using fixed decision trees that cannot adapt to complex learner data, the system treats adjusting the learning challenge as a step-by-step decision problem. The RL agent monitors the learner's progress and chooses changes that maximise a reward based on teaching goals, like keeping students engaged and helping them master the subject.

\quad For stochastic routing, the educational content is broken into separate, self-contained chapters or quizzes. In the reinforcement learning model, these chapters and quizzes act as individual tasks. By dividing up the material, the model creates clear boundaries for calculating rewards and updating its rules before the learner moves on to the next section. The proposed routing system uses ideas from the \textbf{GRADES} framework, which stands for Game-based Reinforcement Learning Adaptive Difficulty and Evaluation with Stealth assessment. It monitors performance continuously and uses hidden assessments to guide the reinforcement learning model~\cite{14}. The main goal is to adjust the difficulty to match the learner's skills without disrupting the flow of gameplay.

\quad The routing system evaluates learners using two methods (Figure~\ref{fig:stealth-quiz}). First, during the visual novel gameplay,  dialogue choices serve as a stealth assessment. Second, at the end of each chapter, learners complete a quiz. The routing model uses both the stealth assessment and the quiz score to decide the next route. If the results show that the learner understands the material, they move on to the next topic chapter. If they struggle, the model guides them to a different chapter of the same topic. If a learner tries all variations and still does not meet the mastery level, the system explains its assessment before moving them on to the next topic. This pipeline is visualised in Figure~\ref{fig:adaptive-pipeline}.

\chapter{Evaluation and Conclusions}

\section{Summary}

\quad This project created a foundational architecture for an adaptable visual novel. A custom visual novel framework was built using the Godot engine, focusing on separate JSON data saving to allow for easy updates to content. The system's interface was designed as a data-tracking system to prepare for future machine learning integration. Features like the Word Bank and History Transcript were included to reduce extra cognitive effort. Lastly, the dialogue systems were arranged to capture learner choices for stealth assessment.


\section{Evaluation of the Project}

Because this paper focused on the infrastructure phase, the evaluation focuses on software design rather than empirical user statistics.

\begin{itemize}
    \item \textbf{Data Telemetry:} The dual-assessment pipeline successfully captures both stealth telemetry (dialogue choices) and quiz scores.

    \item \textbf{Decoupled Architecture:} The engine organises the story into separate, self-contained chapters using JSON. This setup creates distinct states needed for a Markov Decision Process (MDP). This shows that the software is ready to support a routing agent that involves random decision-making.

    \item \textbf{UI/UX Heuristics:} The interface keeps students engaged in the story. It prevents them from having to search external menus for glossaries or game progress.
\end{itemize}


\section{Comparison with Existing Work}

\quad Rjiba et al. studied how to use reinforcement learning to adjust difficulty levels in collaborative game-based learning environments \cite{7}. They created a system called GRADES (Game-based Reinforcement Learning Adaptive Difficulty and Evaluation with Stealth assessment). This system features a layered design that includes smart decision-making, hidden evaluations, and ongoing performance tracking. In contrast, the QZed visual novel uses a similar two-layer system. It mixes hidden assessments, such as interactive dialogue, with direct evaluations, such as quizzes. However, it focuses on a single-player experience rather than a collaborative setting.

\quad Gomes et al. showed that using learning-based strategies can effectively adjust difficulty in healthcare games \cite{11}. They used methods from Reinforcement Learning (RL) and Multi-Armed Bandits (MAB). Their findings showed that MAB algorithms adjusted quickly to changes in rewards compared with full RL methods. To address the initial challenge of having no prior data, they used AI-driven virtual agents to simulate patient symptoms for training before using the system in real life. The QZed project plans to use a similar RL approach for adjusting difficulty. However, it will focus only on data from how users interact with the game, like their dialogue choices and quiz answers, without needing external sensors to guide the model.


\section{Future Work}

\begin{itemize}
    \item \textbf{Deployment and Empirical Study:} The next step is to launch the completed visual novel on the QZed platform for users to test. This will help gather real-world data, such as time spent on tasks, error rates, and pre- and post-test scores. This data will be used to evaluate how much users actually learn.

    \item \textbf{Content Modification:} Future iterations will enable the AI to modify the stories and quizzes. Rather than simply routing a student to a recommended chapter, the AI will adjust the dialogue to target the gaps identified in the learner's stealth assessment.
\end{itemize}
