## Repository Structure

| Directory | Purpose |
| :--- | :--- |
| **`docs/`** | Contains the dissertation paper, including the complete version history of the LaTeX source files. |
| **`data/`** | JSON dictionary assets containing the chapter narratives, dialogue blocks, and quizzes. |
| **`autoloads/`** | Global Singletons, including the core `GameManager`, UI & audio controllers, and history log. |
| **`scenes/`** | Godot `.tscn` files defining the visual novel architecture, Word Bank tooltips, and interactive timelines. |
| **`assets/`** | 2D art, UI design elements exported from Figma, fonts, and tactile audio effects. |
